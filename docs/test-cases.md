# Тест-кейсы

Для каждого функционального требования: шаги ручной проверки в приложении и автоматический тест (`tests/SberProject.Tests`, запуск `dotnet test`). Скриншоты окон лежат в `docs/screenshots/`, ссылки на них — в колонке «Фактический результат».

Автотесты: **82 теста, все проходят** (14.10.2026): ядро и модели представления (`ViewModelTests`). Скриншоты сняты скриптом `tools/ui-smoke.ps1 -OutDir docs/screenshots`: он открывает все окна программы и проверяет, что в журнале нет непредвиденных ошибок.
