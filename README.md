# Сбербанк. Сведения о вкладчиках банка

Курсовая работа по дисциплине «Технологии программирования».

## Описание

Настольное приложение для операциониста банковского отделения. В нем ведется учет вкладчиков и их вкладов: номер лицевого счета, категория вклада, паспортные данные, текущая сумма вклада и дата последней операции. Приложение проводит прием и выдачу любой суммы и автоматически начисляет проценты.

## Функциональность

- открытие вклада: паспортные данные с проверкой формата, выбор категории, первоначальная сумма;
- автоматическая генерация уникального 20-значного номера лицевого счета;
- список вкладов с поиском по номеру счета, ФИО или паспорту, фильтром по категории и сортировкой;
- прием и выдача любой суммы (выдача не больше остатка);
- автоматическое начисление процентов: ежедневно на фактический остаток, капитализация в последний день месяца, досчет пропущенных дней при запуске;
- история операций по каждому счету;
- изменение паспортных данных вкладчика;
- закрытие вклада с выдачей остатка и процентов;
- справочник категорий вкладов: ставка, минимальная сумма открытия, прекращение и возобновление приема новых вкладов;
- хранение данных в JSON-файлах, восстановление при повреждении файла;
- журнал действий пользователя;
- экспорт списка в CSV для Excel.

## Технологии

- C# 13, .NET 9

- Microsoft.Extensions.DependencyInjection — внедрение зависимостей

- xUnit — модульные тесты ядра и моделей представления
- анализаторы .NET, `.editorconfig`, `dotnet format` — предупреждения считаются ошибками
- Visual Studio 2022 / JetBrains Rider

Примененные паттерны (MVVM, команда, DI, репозиторий, единица работы, фабрика и др.) описаны в [docs/plan.md](docs/plan.md#63-примененные-паттерны).

## Структура

```
src/SberProject/          WPF-приложение: окна (Views), модели представления (ViewModels), стили (Resources)
src/SberProject.Core/     бизнес-логика без зависимости от WPF: модели, сервисы, хранение, проверка данных
tests/SberProject.Tests/  модульные тесты
tools/                    ui-smoke.ps1 — автоматическая проверка окон со скриншотами

```

## Запуск

Нужен [.NET SDK 9](https://dotnet.microsoft.com/download) и Windows.

```
dotnet run --project src/SberProject
```

Тесты и проверка стиля:

```
dotnet test
dotnet format --verify-no-changes
```

Проверка всех окон со скриншотами:

```
powershell -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -OutDir docs/screenshots
```

При первом запуске создаются три категории вкладов и четыре демонстрационных вклада. Данные хранятся в папке `data` рядом с исполняемым файлом (`categories.json`, `accounts.json`, `operations.json`), журнал — в `logs/app.log`.
